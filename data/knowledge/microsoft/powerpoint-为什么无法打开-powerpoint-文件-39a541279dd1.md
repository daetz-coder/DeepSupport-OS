# 为什么无法打开 PowerPoint 文件？

应用对象
PowerPoint for iPad
PowerPoint for iPhone

在此版本的 PowerPoint 中，无法打开文件扩展名为 .ppa 或 .ppam 的加载项 (文件) 。

幻灯片放映模式下 PowerPoint 放映文件（.ppsx、.pps 和 .ppsm）不能自动打开。

此版本的 PowerPoint 支持除 PowerPoint 97-2003 文件 (.ppt 和.pps) 以外的所有其他文件类型。 这些文件以只读方式打开，所以不能编辑。
