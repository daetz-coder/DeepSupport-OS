# 使用 Word 中的 Copilot 起草和添加内容

应用对象
Microsoft 365 专属 Word
Microsoft 365 Mac 版专属 Word
Word for iPad
Word for Android 平板电脑版
Word for Android 手机版

如果要在 Microsoft Word 中创建或更新内容，Copilot 可帮助你：

- 开始草稿
- 将新文档与已有的文件、电子邮件或会议相关
- 向现有文档添加内容

注意

如果看不到 Word、Excel、PowerPoint 或 OneNote 中的 Copilot，则它可能不包含在 Microsoft 365 订阅中，或根据组织的设置不可用。 了解你拥有的 Copilot 许可证 。

## 在 Word 中使用 Copilot 开始草稿

在 Word 中使用 Copilot 开始草稿时，请在请求中尽可能详细。 提供的信息越多，Copilot 在草稿中就越有用和更具体。

提示

为了获得更好的结果，请为 Copilot 提供更多的上下文。 例如，如果你有一个大纲或一个 Copilot 可以处理的列表，请将其包含在提示符中。 有关提示的详细信息，请参阅 烹饪一个很好的提示：充分利用 Copilot 。

- 启动 新的空白Word文档 。
- 在 “Copilot 提示符”框中，键入或粘贴提示符。 例如，Write a proposal for a new flavor in the Fourth Coffee latte lineup。 提示 如果要要求 Copilot 使用现有文档作为源 ，请键入 / ，然后键入文档的名称，或者在打开的窗格中选择 “Files ”，然后从列表中选择文档。 如果你有Copilot Pro (家庭) 帐户，则仅当你使用 web Word 时，此选项才可用。
- 选择“ 生成 ”，Copilot 将为你草稿新内容。
- Copilot 生成内容后，选择“ 保留它 以保留内容 ”以重新生成响应; ）以放弃内容，或者通过在撰写框中输入详细信息（如 Make it more concise或 ...） for the holiday lineup来微调草稿 。

重要

请记住，Copilot 生成草稿。 需要验证和修改详细信息，以确保其是否准确并符合语气和风格。

下面是你可能想要尝试的一些提示建议。 复制或修改它们以满足你的需求。

- Write an article on the importance of creating work/life balance.
- Write a white paper about project management.
- 为 Contoso 的销售职位写招聘信。 入职日期为 8 月 1 日，年薪为 60,000 美元，外加奖金。

## 从文件、电子邮件或会议 (或多个文件开始！)

注意

若要使用此功能，需要符合条件的 Microsoft 365 订阅和/或 智能 Microsoft 365 Copilot 副驾驶® 许可证。 请参阅 在哪里可以获取 智能 Microsoft 365 Copilot 副驾驶®?

Copilot 还可以基于文件、电子邮件或会议中的新草稿。 在提示框中，描述希望 Copilot 生成的内容，然后在提示符中输入 / ，并开始键入要链接的文件名。 创建新文档时，最多可以选择 20 个项目供 Copilot 引用。

- 为什么要添加文件、电子邮件或会议？ 当你提供参考时，Copilot 能够更好地提供更相关、更准确的草稿，这些草稿以公司的特定术语、数据和 KPI 为依据，从而通过拉取重要的详细信息并减少一般响应来节省时间。
- 安全： 将草稿放在特定材料上时，企业数据和敏感信息将安全地保存在组织中。 有关详细信息，请参阅 Microsoft Copilot的隐私常见问题解答 。

若要使用文件，你必须有权在你组织的 SharePoint 或 OneDrive 中访问它们。 它们可以是Word、PowerPoint、PDF 或 TXT 文件。

## 向现有文档添加内容

注意

若要使用此功能，需要符合条件的 Microsoft 365 订阅和/或 智能 Microsoft 365 Copilot 副驾驶® 许可证。 请参阅 在哪里可以获取 智能 Microsoft 365 Copilot 副驾驶®?

留在流程中，让 Copilot 帮助你向文档添加更多内容。

### 起草新内容

- 转到新的空白行。
- 在文档左边距Word选择 。
- 在提示框中，告诉 Copilot 你想要什么。
- Copilot 提供其他内容后，可以选择“ 保留”、“ 重新生成 ”、“ 放弃它 ”，或者通过在撰写框中输入详细信息来微调 Copilot 的响应，例如Make it sound professional.

### 带有已选定内容的草稿

让 Copilot 根据你提供的信息增强和创建内容。

- 在 Word 文档中，选择希望 Copilot 处理的文本、列表或表格。
- 在文档左边距Word选择 。
- 在提示框中，告诉 Copilot 你希望对所选文本执行哪些操作。 如果对 Web 使用 Word，Copilot 将在原始文本中保留粗体、斜体或下划线。 注意 我们将逐步推出格式保留期，因此，如果你尚未看到它，请继续在更新中监视它。 有关详细信息，请参阅 在Windows 11中实现持续创新 。
- Copilot 提供其他内容后，可以选择“ 保留”、“重新生成 ”或“ 放弃”。 还可以通过在 Copilot 撰写框中输入详细信息来改进响应，例如 Fine tune this draft.
