# Outlook for Mac和 Outlook Mobile 间歇性停止同步

应用对象
Microsoft 365 Mac 版专属 Outlook
Outlook for Android
Outlook for iOS

上次更新时间：2025 年 10 月 30 日

问题

Outlook for Mac和 Outlook Mobile 间歇性停止同步，出现以下错误：

- Outlook Mobile ：再次添加帐户。 同步 emailaddress 时遇到问题。 请再次添加帐户。
- Outlook for Mac ：Emailaddress：我们在同步邮箱时遇到问题。 请再次删除并添加帐户。

状态：正在调查

Outlook 团队正在调查此问题以便开发修补程序。 我们会在了解详细信息后立即更新本主题。

解决 方案

- 打开 Outlook Web 应用。
- 转到 “People ”窗格。
- 选择用户邮箱下的“ 收藏夹 ”。
- 删除所有 收藏夹联系人 。
