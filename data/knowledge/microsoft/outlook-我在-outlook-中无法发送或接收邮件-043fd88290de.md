如果 Outlook 发件箱中出现邮件堆积，或者你向其发送邮件的人员未收到邮件，请尝试以下方法来解决问题。

- 新版 Outlook
- 经典 Outlook

注意

如果Microsoft云存储空间已满，则无法发送或接收电子邮件。 检查邮箱 存储 ，了解占用空间的情况。 详细了解最近的更改 。

## 确保已连接到 Internet

- 打开浏览器，例如 Microsoft Edge 或 Google Chrome。
- 尝试在地址栏中输入以下任一网站： http://www.microsoft.com http://www.bing.com
- 如果无法访问这两个网站中的任何一个，请参阅 修复 Windows 中的网络连接问题 。

如果这不能解决问题，请参阅下一节。

## 检查是否遇到同步问题

如果遇到同步问题，可以通过功能区上的“ 视图 ”选项卡选择“ 同步 ”按钮来强制手动同步。 Outlook 同步时，邮件列表底部会显示状态消息。 有关详细信息，请转到 同步以手动检查新邮件并在 Outlook 中发送邮件 。

注意

Gmail、Yahoo、iCloud 或通用 POP 和 IMAP 等第三方电子邮件帐户没有使用按钮手动同步的功能。

如果这不能解决问题，请参阅下一节。

## 邮件是否包含大型附件？

一些电子邮件提供商（如 ISP 或 Gmail）不允许发送超过特定大小的邮件。 向邮件添加图片和大型附件可能导致无法发送该邮件（以及在该大型邮件后发送的所有邮件）。

转到“ 发件箱 ”，然后打开滞留的电子邮件。 从最早的邮件开始。 如果该邮件的附件大于 20MB，请删除附件并附加较小的文件或附加附件的链接。 有关详细信息，请转到 减小附件大小以使用 Outlook 或 Exchange Online限制 发送大型文件。

现在请尝试再次发送邮件。 如果这不能解决问题，请参阅下一节。

## 最近是否更改了密码？

如果你已在网站上更改了电子邮件帐户的密码，则还需要在新 Outlook 中更改密码。

- 选择电子邮件帐户名称旁边的图标。
- 将显示一个弹出窗口，提示你登录。 选择“ 继续 ”。
- 按照提示输入新密码登录。

有关详细信息，请转到 重置忘记的Microsoft帐户密码 。

如果你知道你的电子邮件帐户使用了正确的密码，并且看到这样的消息： 请在电子邮件提供商的网站上为 Outlook 创建应用密码 。

- 转到电子邮件提供商以获取应用密码。 电子邮件提供商将提供有关如何生成应用密码的说明，以便在电子邮件应用程序（如 Outlook）中使用，以代替常规密码。
- 从提供商处获取应用密码后，复制该密码，然后在 Outlook 中提示输入帐户密码时粘贴该密码。

有关详细信息，请访问 将电子邮件帐户添加到 Outlook for Windows 。

## 经典 Outlook 是否断开连接？ 检查 Outlook 窗口底部

在 Outlook 状态栏上，如果看到 “已断开连接 ”、“ 脱机工作 ”或 “正在尝试连接...” ，则 Outlook 无法访问电子邮件服务器来发送邮件。

若要解决此问题，请在功能区上选择“ 发送/接收 ”选项卡，然后在 “首选项” 组中，选择“ 脱机工作 ”，在脱机模式和联机模式之间切换。 可能需要打开邮件并再次发送，或选择“ 发送/接收 ”。

如果这不能解决问题，请参阅下一节。

## 确保已连接到 Internet

如果失去与 Internet 的连接，经典 Outlook 将无法发送邮件。

- 打开浏览器，例如 Microsoft Edge 或 Google Chrome。
- 尝试在地址栏中输入以下任一网站： http://www.microsoft.com http://www.bing.com
- 如果无法访问这两个网站中的任何一个，请参阅 修复 Windows 中的网络连接问题 。

如果这不能解决问题，请参阅下一节。

## 最近是否更改了密码？

如果你已在网站上更改了电子邮件帐户的密码，则还需要在经典 Outlook 中更改密码。 有关详细信息，请转到 重置忘记的Microsoft帐户密码 。

## 请与防病毒软件支持人员联系

一些防病毒程序会扫描电子邮件。 如果发现病毒，在清理病毒之前，防病毒软件可能会阻止发送或接收更多电子邮件。

## 修复经典 Outlook 程序

有时，可能需要修复 Outlook 程序。 修复过程很简单，但可能需要半小时才能完成。 有关详细信息，请参阅 修复 Office 应用程序 。

## 修复经典 Outlook 配置文件

配置文件是一组用于控制 Outlook​​ 工作方式的设置。 它包括帐户列表、自动完成信息及姓名和缩写。 要修复 Outlook​​ 配置文件或新建配置文件，请参阅 通过修复配置文件解决 Outlook 电子邮件连接问题 。

## 在安全模式下启动经典 Outlook

有时，Outlook 加载项会崩溃并阻止发送电子邮件。 要禁用所有加载项，可在安全模式下启动 Outlook。 如果 Outlook 在安全模式下可发送电子邮件，那么新建 Outlook 电子邮件配置文件后应能再次发送电子邮件。

若要在安全模式下启动 Outlook，请按键盘上的 Windows 键。 在搜索框中，键入 outlook.exe /safe ，然后按 Enter。

要详细了解如何新建电子邮件配置文件，请参阅 创建 Outlook 配置文件 。

## 运行收件箱修复工具

对于多种类型的电子邮件帐户，经典 Outlook 会将邮件存储在个人文件夹文件 (.pst 文件中) 。 通过运行收件箱修复工具可修复此文件。 此修复应需要 15 分钟左右。 有关详细信息，请参阅 修复 Outlook 个人文件夹文件 (.pst) 。
