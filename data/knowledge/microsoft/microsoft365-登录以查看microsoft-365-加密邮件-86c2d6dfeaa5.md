# 登录以查看Microsoft 365 加密邮件

应用对象
Office 365 小型企业版

如果已收到来自使用 Microsoft 365 消息加密的组织发送的加密邮件，则可以使用 Microsoft 帐户或用于 Microsoft 365 的工作或学校帐户登录以查看邮件。 如果没有Microsoft帐户，可以按照此过程创建一个帐户。

## 开始之前

什么是Microsoft帐户？

Microsoft帐户是用于登录Microsoft服务（如 Outlook.com、OneDrive、Windows Phone 或 Xbox Live）的电子邮件地址和密码。 什么是Microsoft帐户？ 是一个简短的视频，有助于了解什么是Microsoft帐户及其使用方式。

我已经有一个Microsoft帐户。 是否需要创建一个新帐户来查看加密邮件？

不需要。 可以参阅 发送、查看和答复加密邮件 ，了解如何使用现有帐户登录并查看加密邮件。

## 创建用于查看加密邮件的Microsoft帐户

此过程将引导你完成创建Microsoft帐户的过程。

若要创建Microsoft帐户以查看加密邮件，请执行以下操作：

- 打开“收件箱”中的邮件。 主题行可能指示邮件已加密。 以下屏幕截图显示了包含加密邮件的 Gmail“收件箱”。 注意 您可以使用 Hotmail、Yahoo 或 Gmail 等任何电子邮件服务查看加密邮件。 打开邮件后，你将看到 Microsoft 365 的邮件加密 和名为 message.html 的附件。 打开附件。
- 选择“ 登录并查看您的加密邮件 ”。
- 选择创建Microsoft帐户的选项。
- 填写“ 创建帐户 ”表单。 您将在“ 用户名 ”框中看到您的电子邮件地址。
- 查看摘要页并选择“ 验证您的电子邮件地址 ”。 您将收到验证电子邮件。
- 打开验证电子邮件并选择“验证”按钮以确认您的电子邮件地址。
- 验证电子邮件地址后，请返回并打开开始使用的 message.html 文件。 现在可以使用 Microsoft 帐户登录并查看加密邮件。
