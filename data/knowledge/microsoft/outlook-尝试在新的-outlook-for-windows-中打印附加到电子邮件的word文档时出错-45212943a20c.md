# 尝试在新的 Outlook for Windows 中打印附加到电子邮件的Word文档时出错

应用对象
新的 Outlook for Windows

上次更新时间：2025 年 5 月 22 日

问题

如果用户在新 Outlook 中收到附加了Word文档的电子邮件，请选择在并排窗口中预览该电子邮件，然后选择“ 打印 ”按钮，将显示一个带有 “打开 PDF ”按钮的Microsoft Word对话框。 当用户选择“ 打开 PDF ”按钮时，他们可能会遇到以下情况：

- 不会发生任何操作
- 默认浏览器将打开一个标题为 “服务器错误” 的新窗口，并显示一个错误：： 404 - 找不到文件或目录。 要查找的资源可能已删除、名称已更改或暂时不可用。

Excel 或 PowerPoint 文件不会发生此问题。 Outlook 网页版中也不会发生此问题。

状态：正在调查

Outlook 团队正在调查此问题以便开发修补程序。 有关详细信息，我们将更新本文。

解决 方案

可以使用 web 上的Word或Word桌面应用来打印文档。

在并排预览窗口中打开Word文档后，选择顶部的“ 在Word中打开 ”按钮，然后选择“ 在 web 上的Word中打开 ”或“ 在桌面应用中Word打开 ”，然后打印文档。
