## 链接Microsoft个人帐户

无法链接、合并或合并Microsoft个人帐户，并且无法将游戏进度或玩家代号、帐户购买和余额等内容从一个帐户转移到另一个帐户，但帐户可以并排使用。

- 将帐户添加到 Outlook 。 不能将其他Microsoft帐户 (当前或已关闭) 添加为 帐户别名 ，但可以将其他Microsoft、Gmail 或工作/学校电子邮件添加到 Outlook。 了解如何操作 。
- OneDrive 。 可以使用 OneDrive 同步工作或学校文件和个人文件。 存储保持独立，因此无法将工作或学校文件夹同步到 OneDrive 个人文件夹，但可以将文件从一个复制或拖放到另一个文件夹。 了解详细信息 。
- 共享订阅 。 如果你有Microsoft 365 家庭版订阅，可以与其他最多 5 个人 共享你的订阅 及其权益。 你共享的帐户不会链接，除非你) 共享文件或照片 ，否则电子邮件、OneDrive 文件 & 照片将保持私密 (。
- 加入家庭组 。 如果你是 Family Safety 组的组织者，则可以 将其他帐户添加为成员 。 成员可以查看其“家庭”组中的其他人，但只有组织者可以查看Family Safety活动报告。
- 在电脑上添加帐户 。 在共享的 Windows 电脑上拥有不同的帐户可让多人使用同一设备，同时为每个人提供自己的登录信息、访问自己的文件、浏览器收藏夹和桌面设置。 了解详细信息 。
- Xbox 配置文件 ：如果有多个 Xbox 配置文件，可以通过执行 几个简单的步骤 在配置文件之间切换。
- 设置Microsoft Edge 配置文件 。 配置文件允许不同的用户在共享环境中操作，同时保持对其个性化浏览器设置、书签和扩展的访问权限。 了解如何操作 。

## 链接Microsoft个人帐户和工作/学校帐户

无法将工作或学校帐户合并或合并为Microsoft个人帐户，但与个人帐户一样，可以通过多种方式并行使用帐户。

- 将帐户添加到 Outlook 。 不能将其他Microsoft帐户 (当前或已关闭) 添加为 帐户别名 ，但可以将其他Microsoft、Gmail 或工作/学校电子邮件添加到 Outlook。 了解如何操作 。
- OneDrive 。 可以使用 OneDrive 同步工作或学校文件和个人文件。 存储保持独立，因此无法将工作或学校文件夹同步到 OneDrive 个人文件夹，但可以将文件从一个复制或拖放到另一个文件夹。 了解详细信息 。
- 在电脑上添加帐户 。 在共享的 Windows 电脑上拥有不同的帐户可让多人使用同一设备，同时为每个人提供自己的登录信息、访问自己的文件、浏览器收藏夹和桌面设置。 了解详细信息 。
- 设置Microsoft Edge 配置文件 。 配置文件允许不同的用户在共享环境中操作，同时保持对其个性化浏览器设置、书签和扩展的访问权限。 了解如何操作 。
- Microsoft奖励 。 使用工作或学校帐户在 Windows 或必应中搜索而获得的任何Microsoft Rewards 积分都将计入你的Microsoft个人帐户。 此功能确实包含帐户链接，但必须由 IT 管理员启用。 了解详细信息 。
