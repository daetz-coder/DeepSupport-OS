# PowerPoint 中演示文稿的密码保护

应用对象
Microsoft 365 专属 PowerPoint
Microsoft 365 Mac 版专属 PowerPoint
PowerPoint 2024
PowerPoint 2024 for Mac
PowerPoint 2021
PowerPoint 2021 for Mac
PowerPoint 2019
PowerPoint 2016

密码有助于防止其他人打开或修改演示文稿。

警告

如果为演示文稿创建了密码，请记下该密码并将其放在安全的位置。 如果丢失了密码，则无法检索该密码，并且你将无法打开或访问演示文稿。

- Windows
- macOS
- Web

## 向文件添加密码保护

- 选择“ 文件 > 信息 ”。
- 选择“ 使用密码 保护演示文稿 >加密”。
- 在“ 密码 ”框中，输入要使用的密码。 选择“ 确定 ”。
- PowerPoint 会再次输入密码来提示你确认密码。
- 保存文件以确保密码生效。

PowerPoint for ODP (打开文档演示文稿) 文件中不支持密码保护。

## 从文件中删除密码

删除文档密码的流程非常简单，但您必须知道原始密码。

- 打开要删除其密码的演示文稿。
- 选择“ 文件 > 信息 ”。
- 选择“ 使用密码 保护演示文稿 >加密”。
- 清除“密码”框中 的密码 ，然后单击“ 确定 ”。

## 需要密码才能修改演示文稿

你可以添加密码，以便只有经过授权的用户才能修改演示文稿。 未经授权的用户仍可以打开演示文稿，然后使用不同的文件名保存它。

- 单击“ 文件 > 另存为 > ”选择一个位置，然后选择“ 更多选项” 以显示“Windows 位置”对话框
- 展开 “工具”下拉列表 ，然后选择“ 常规选项”
- 在“ 要修改 的密码”框中输入所需的密码，然后单击“确定”

提示

若要删除密码，请返回到“ 常规选项” 对话框，清除“ 要修改的密码 ”框，单击“ 确定” ，然后保存演示文稿。

## 共同创作受密码保护的文件

如果尝试打开其他人当前正在处理的受密码保护的文件，则可以打开该文件，但无法对其进行编辑。 你将看到处于只读模式的文件。

## 需要密码才能打开演示文稿

- 单击“ 文件 > 密码 ”。
- 在 “要打开的密码 ”下，选择“ 加密此演示文稿并需要密码才能打开 检查”框。
- 在“ 新密码 ”框中键入密码。 注意 若要创建强密码，请至少使用 7 个字符，并包含大小写字母、数字和非字母字符的组合，例如 ！、$、#和 %。 请勿包含你的帐户名称或其他个人信息。
- 在“ 验证 ”框中，再次键入密码，然后单击“ 设置密码 ”。
- 单击“ 确定 ”，然后保存演示文稿。 提示 要删除密码，请清除“ 加密此演示文稿并要求须有密码才能打开 ”复选框，单击“ 确定 ”，然后保存演示文稿。

## 需要密码才能修改演示文稿

你可以添加密码，以便只有经过授权的用户才能修改演示文稿。 未经授权的用户仍可以打开演示文稿，然后使用不同的文件名保存它。

- 单击“ 文件 > 密码 ”。
- 在 “要修改的密码 ”下，选择“ 需要密码才能修改演示文稿 检查框。
- 在“ 新密码 ”框中键入密码。 注意 若要创建强密码，请至少使用 7 个字符，并包含大小写字母、数字和非字母字符的组合，例如 ！、$、#和 %。 请勿包含你的帐户名称或其他个人信息。
- 在“ 验证 ”框中，再次键入密码，然后单击“ 设置密码 ”。
- 单击“ 确定 ”，然后保存演示文稿。

提示

若要删除密码，请清除“ 需要密码才能修改演示文稿 检查”框，单击“ 确定 ”，然后保存演示文稿。

## 更改密码以打开或修改演示文稿

- 单击“ 文件 > 密码 ”。
- 在 “要打开的密码” 或“ 要修改的密码 ”下，单击“ 更改密码 ”。
- 在“ 新建密码 ”框中，键入新密码。 注意 若要创建强密码，请至少使用 7 个字符，并包含大小写字母、数字和非字母字符的组合，例如 ！、$、#和 %。 请勿包含你的帐户名称或其他个人信息。
- 在“ 验证 ”框中，再次键入密码，然后单击“ 设置密码 ”。
- 单击“ 确定 ”，然后保存演示文稿。

打开受密码保护的演示文稿：在框中输入文件的密码。

密码区分大小写。 确保未意外打开 Caps Lock。

如果输入的密码不正确，可以重试。

没有密码，无法打开文件。 如果不知道密码，则必须与加密文件的人员检查。

如果尝试打开其他人当前正在处理的受密码保护的文件，则可以打开该文件，但无法对其进行编辑。 你将看到处于只读模式的文件。

对于 ODP (打开文档演示文稿) 文件，PowerPoint 网页版不支持密码保护。
