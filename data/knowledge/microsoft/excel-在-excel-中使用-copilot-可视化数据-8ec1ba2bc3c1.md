# 在 Excel 中使用 Copilot 可视化数据

应用对象
Microsoft 365 专属 Excel
Microsoft 365 Mac 版专属 Excel
Excel for iPad
Excel Web App

Excel 中的 Copilot 可帮助你将数据转换为视觉对象，并向前显示重要部分。 要求 Copilot 创建图表和数据透视表，或者突出显示、排序和筛选数据。 使用本文中的提示想法作为起点。

若要打开 Copilot，请选择 Excel 右下角的 Copilot 图标。 如果你不熟悉 Excel 中的 Copilot，请参阅 Excel 中的 Copilot 入门 。

注意

与任何 AI 生成的内容一样，请查看、编辑和验证 Copilot 为你创建的任何内容。

## 创建图表

如果想要以图表的形式查看数据，Copilot 可以创建一个。 描述所需的图表，然后 Copilot 生成它。

在 X 轴上创建供应商预算和 Y 轴上的员工人数的图表。

创建显示随时间变化的折线图。显示数据标签和网格线。

显示一个图表，该图表将范围中的位置与多样性统计（如代系、种族和性别）进行比较。

## 创建数据透视表

如果要汇总大型数据集，Copilot 无需手动步骤即可生成数据透视表。 包含的详细信息越多，结果就越有用。 如果建议与所需内容不匹配，请添加更多详细信息并要求 Copilot 再次生成。

创建数据透视表。

根据此数据创建数据透视表，并按报表日期显示摘要。

创建一个数据透视表，其中包含销售额的总和，月份以行为单位，类别为列。

## 突出显示、排序和筛选

Copilot 可以通过突出显示、排序和筛选数据来提醒关注重要事项。 Copilot 描述聊天窗格中的更改，你选择“ 应用 ”以在工作表中查看更改。

将前 10 个值加粗。

突出显示销售单位中的最低值。

从最低到最高对参与率进行排序。

筛选以显示下周到期的项目。
