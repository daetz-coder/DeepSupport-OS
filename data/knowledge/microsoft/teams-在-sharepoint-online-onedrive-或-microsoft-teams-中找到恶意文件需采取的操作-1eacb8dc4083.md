## 删除 (建议) 的文件

若要保护自己、计算机和组织，最佳选择是删除文件。 在 OneDrive 移动应用中， 你唯 一的选择是删除文件。

- 在移动应用上选择要删除 (的文件，选择文件) 旁边的“ 更多 ”图标。
- 单击“ 删除 ”。 在 OneDrive 移动应用中删除

## 为何阻止 SharePoint、OneDrive 或 Microsoft Teams 中的文件？

文件被阻止，以帮助保护你、你的计算机和组织免受恶意软件的侵害。

Microsoft 365 中提供了某些安全功能，因此可以在 Microsoft 365、OneDrive for work 或 school 或 Microsoft Teams 的 SharePoint 中识别恶意文件。 如果 SharePoint、OneDrive 或 Microsoft Teams 中的文件被视为恶意文件，则会阻止该文件，以便没有人能够打开它。 被阻止的文件在其文件名后面有一个标记，如下所示：

尽管阻止文件可能不方便，但感染恶意软件的情况更糟。 网络罪犯使用 勒索软件 、 技术支持欺诈 或 不需要的软件 来危害用户和计算机。 一旦网络罪犯获得用户凭据或敏感信息的访问权限，他们就可以使用该信息来访问更多信息或其他用户，甚至收取欺诈性费用。 若要了解详细信息，请参阅 了解不同的恶意软件类型 。

## 我该怎么做才能避免将来遇到恶意文件？

尽管网络罪犯继续寻找新的方法来欺骗恶意软件用户，但你可以采取一些步骤来帮助保护你和你的计算机。

- 在计算机上运行安全软件，并使该软件保持最新。 请参阅 使用 Windows 安全中心 App Defender 保持保护 。
- 在所有设备上安装最新的软件更新。 请参阅 Windows 更新：常见问题解答 。
- 请谨慎处理电子邮件附件和文件。 请参阅 如何识别钓鱼电子邮件、链接或电话呼叫 。

若要详细了解恶意软件的工作原理以及如何防止恶意软件感染，请参阅 防止恶意软件感染 。

## 如果我认为系统出错，该怎么办？

如果你的组织使用 Microsoft Defender 进行Office 365并且阻止了你认为不应该阻止的文件，则需要一些Microsoft 365 管理员的帮助，该管理员可以研究问题并可能取消阻止该文件。 若要详细了解 Microsoft 365 管理员执行的操作，请参阅 关于 Microsoft 365 管理员角色 。
