## OneDrive 中的 Copilot 概述

OneDrive 中的 Copilot 是一种创新的 AI 支持助手，旨在彻底改变与文件交互的方式并简化工作流。

管理大量文件可能非常耗时，Copilot 旨在解决一个中心问题：在专注于实际任务之前，减少所需的准备工作。

此智能工具通过五个关键方式增强 OneDrive 体验：

- 提出问题 ：从 OneDrive 中的多个文件中提取信息，甚至无需打开它们。
- 比较文件 ：只需单击一下即可评估文档之间的主要差异。
- 收听文件 ：借助 Web 上的 OneDrive 中的 Copilot，工作或学校用户现在可以生成包含脚本的Word文档、PDF 和 Teams 会议录制的音频概述。
- 汇总文件 ：在 OneDrive 中快速概述文件，以便在重要文件上保持更新不会花费数小时。
- 通过文档 生成见解 ，并在 Copilot 的帮助下快速开始工作。
- 使用 OneDrive 中的 上下文菜单 快速高效地查看 PDF。

通过集成这些功能，OneDrive 中的 Copilot 可转换文件管理过程，使你能够在与文件相关的传递上花费更少的时间，将更多时间花在有意义的工作上，从而最终提高数字工作区的生产力和效率。

注意

OneDrive 中的 Copilot 可通过 OneDrive 网站和 Windows 电脑获取。 你需要Microsoft 365 个人版或家庭订阅，或者拥有具有 Copilot 许可证的工作或学校帐户。

OneDrive 中的 Copilot 即将推出，因此并非所有功能都可供世界各地的所有用户使用。
