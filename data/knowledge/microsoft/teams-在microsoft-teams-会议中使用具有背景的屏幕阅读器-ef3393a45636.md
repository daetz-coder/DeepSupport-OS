# 在Microsoft Teams 会议中使用具有背景的屏幕阅读器

应用对象
Microsoft Teams

本文适用于使用屏幕阅读器程序（如 Windows 讲述人、JAWS 或 NVDA）与 Windows 工具或功能以及Microsoft 365 产品的用户。 本文是 Office 内容集 辅助功能帮助和学习 的 一部分，可在其中找到有关应用的更多辅助功能信息。 如需一般帮助，请访问 Microsoft 支持部门 。

- Windows
- macOS
- iOS
- Web

将 Microsoft Teams for Windows 与键盘和屏幕阅读器配合使用，更改会议期间视频中你身后显示的内容。 这也称为背景、背景效果或背景筛选器。 我们已使用 JAWS 和 NVDA 对其进行了测试，但它可能与其他屏幕阅读器配合使用，只要它们遵循常见的辅助功能标准和技术。

你将了解如何在加入会议之前或会议期间更改背景效果、关闭效果、模糊或取消模糊背景，或上传自定义背景效果。 你还将了解Microsoft Teams 附带的背景效果，以便轻松选择合适的效果。

更改背景效果后，在再次更改背景之前，相同的效果将持续用于所有未来的会议。

注意

- Microsoft 365 的新增功能会逐渐向 Microsoft 365 订阅者发布，因此你的应用可能还没有这些功能。 若要了解如何更快速地获取新功能，请 加入 Office 预览体验计划 。
- 要详细了解屏幕阅读器，请转到 如何配合使用屏幕阅读器和 Microsoft 365 。
- 最新版本的 JAWS 不再将虚拟电脑光标模式设置为 Microsoft Teams 的默认值。 有关如何打开虚拟电脑光标模式的说明，请转到 启用 JAWS 虚拟光标 。
- 如果你通过优化的虚拟桌面基础结构 (VDI) 使用 Microsoft Teams，则不支持后台效果。

## 在加入会议之前更改背景

在实际加入会议之前，可以在设置视频和音频时更改背景。

屏幕阅读器导航

### 焦点导航

- 在“Microsoft Teams Calendar ”视图中，导航到要加入的会议，然后按 Enter。 导航到“ 加入 ”按钮，然后按 Enter。 有关如何加入会议的详细说明，请参阅 使用屏幕阅读器在 Microsoft Teams 中加入会议。
- 此时会打开用于设置视频和音频的对话框。 按 Tab 键，直到听到“视频选项工具栏，相机检查框，未选中”，然后按空格键打开相机。 如果听到“相机检查框，已选中”，则相机已打开，你可以继续下一步。
- 按一次向右键。 将听到：“显示背景选项按钮。按 Enter。
- “ 背景设置 ”窗格随即打开，焦点将移动到窗格。 将听到：“无选择”。使用箭头键查找所需的背景，然后按空格键将其选中。 有关每个预先设计Microsoft Teams 背景的信息，请参阅 当前可用背景效果的说明 。
- 准备就绪后，完成音频和视频设置，并按照 使用屏幕阅读器加入 Microsoft Teams 中的会议中的指示加入会议。

### 虚拟导航

注意

在 NVDA 中，称为浏览模式。 在 JAWS 中，称为虚拟光标模式。

- 在“Microsoft Teams Calendar ”视图中，导航到要加入的会议，然后按 Enter。 导航到“ 加入 ”按钮，然后按 Enter。 有关如何加入会议的详细说明，请参阅 使用屏幕阅读器在 Microsoft Teams 中加入会议。
- 此时会打开用于设置视频和音频的对话框。 使用 NVDA 时，按 SR 键+空格键切换到虚拟模式。 使用 JAWS 时，按 SR 键+Z。 然后按 B，直到听到“视频选项工具栏，显示背景选项按钮”，然后按空格键。 如果听到“视频选项工具栏，打开视频”，则相机未打开。 若要打开相机，请按一次向左键，然后按空格键。 将听到：“相机已打开。按 B 一次，然后按空格键。
- “ 背景设置 ”窗格随即打开，焦点将移动到窗格。 将听到：“无选择”。使用箭头键查找所需的背景，然后按空格键将其选中。 有关每个预先设计Microsoft Teams 背景的信息，请参阅 当前可用背景效果的说明 。
- 准备就绪后，完成音频和视频设置，并按照 使用屏幕阅读器加入 Microsoft Teams 中的会议中的指示加入会议。

## 在会议期间更改背景

即使会议已经开始，也可以更改背景。

屏幕阅读器导航

### 焦点导航

- 在Microsoft Teams 会议中，按 Tab 键，直到听到：“会议控件区域，工具栏，关闭相机。
- 按向左键，直到听到“更多操作”，然后按 Enter。
- 按向下键，直到听到“应用背景效果”，然后按 Enter。
- “ 背景设置 ”窗格随即打开，焦点将移动到窗格。 将听到：“无选择”。使用箭头键查找所需的背景，然后按空格键将其选中。 有关每个预先设计Microsoft Teams 背景的信息，请参阅 当前可用背景效果的说明 。
- 若要在会议中显示所选背景，请按 Tab 键，直到听到“应用”，然后按 Enter。

### 虚拟导航

注意

在 NVDA 中，称为浏览模式。 在 JAWS 中，称为虚拟光标模式。

- 在 Microsoft Teams 会议中，按 B，直到听到“更多操作按钮”，然后按 Enter。
- 按向左键，直到听到“更多操作，菜单按钮”，然后按 Enter。
- 按向下键，直到听到“应用背景效果”，然后按 Enter。
- “ 背景设置 ”窗格随即打开，焦点将移动到窗格。 将听到：“无选择”。使用箭头键查找所需的背景，然后按空格键将其选中。 有关每个预先设计Microsoft Teams 背景的信息，请参阅 当前可用背景效果的说明 。
- 若要在会议中显示所选背景，请按 B，直到听到“应用”，然后按 Enter。

## 模糊背景

为了确保在Microsoft Teams 会议中使用摄像机时不会发生令人尴尬或分散注意力的事情，可以在会议之前或会议期间模糊背景。

屏幕阅读器导航

### 焦点导航

- 无论你是已在会议中，还是只是为会议设置，都按照 在加入会议前更改背景或更改会议 背景 中的指示导航到“ 背景设置 ”窗格。
- 在“ 背景设置 ”窗格中，使用箭头键，直到到达“ 模糊 ”按钮，然后按 Enter。
- 如果已加入会议，请按 Tab 键，直到听到“应用”，然后按 Enter。 如果尚未加入会议，则会自动应用背景模糊效果。

### 虚拟导航

注意

在 NVDA 中，称为浏览模式。 在 JAWS 中，称为虚拟光标模式。

- 无论你是已在会议中，还是只是为会议设置，都按照 在加入会议前更改背景或更改会议 背景 中的指示导航到“ 背景设置 ”窗格。
- 在“ 背景设置 ”窗格中，使用箭头键，直到到达“ 模糊 ”按钮，然后按 Enter。
- 如果已加入会议，请按 B，直到听到“应用”，然后按 Enter。 如果尚未加入会议，则会自动应用背景模糊效果。

- 如果已加入会议，请按 Tab 键，直到听到“应用”，然后按 Enter。 如果尚未加入会议，则会自动关闭背景效果。

## 使用自定义背景效果

如果想要使用自己的一张图片作为背景效果，而不是预先设计的图像，则可以从计算机上传图像。 在加入会议之前或会议期间，可以上传并开始使用自定义效果。

屏幕阅读器导航

### 焦点导航

- 无论你是已在会议中，还是只是为会议设置，都按照 在加入会议前更改背景或更改会议 背景 中的指示导航到“ 背景设置 ”窗格。
- 在“ 背景设置 ”窗格中，按 Shift+Tab，直到听到“新增”，然后按 Enter。
- Windows 的“ 打开 ”对话框将打开。 导航到要用作背景的图像。 进入图像后，按 Enter。 图像将添加到背景列表中。
- 如果已加入会议，请按 Tab 键，直到听到“应用”，然后按 Enter 将上传的图像用作背景。 如果尚未加入会议，则会自动应用自定义背景效果。

### 虚拟导航

注意

在 NVDA 中，称为浏览模式。 在 JAWS 中，称为虚拟光标模式。

- 无论你是已在会议中，还是只是为会议设置，都按照 在加入会议前更改背景或更改会议 背景 中的指示导航到“ 背景设置 ”窗格。
- 在 “背景设置 ”窗格中，按 B 或 Shift+B，直到听到“新增”，然后按 Enter。
- Windows 的“ 打开 ”对话框将打开。 导航到要用作背景的图像。 进入图像后，按 Enter。 图像将添加到背景列表中。
- 如果已加入会议，请按 B，直到听到“应用”，然后按 Enter 将上传的图像用作背景。 如果尚未加入会议，则会自动应用自定义背景效果。

- 无论你是已在会议中，还是只是为会议设置，都按照 在加入会议前更改背景或更改会议 背景 中的指示导航到“ 背景设置 ”窗格。
- 在 “背景设置 ”窗格中，按 B 或 Shift+B，直到听到“新增”，然后按 Enter。
- Windows 的“ 打开 ”对话框将打开。 导航到要用作背景的图像。 进入图像后，按 Enter。 图像将添加到背景列表中。
- 如果已加入会议，请按 B，直到听到“应用”，然后按 Enter 将上传的图像用作背景。 如果尚未加入会议，则会自动应用自定义背景效果。
