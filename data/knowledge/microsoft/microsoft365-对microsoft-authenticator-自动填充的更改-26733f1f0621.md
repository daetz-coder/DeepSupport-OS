# 对Microsoft Authenticator 自动填充的更改

# 对Microsoft Authenticator 自动填充的更改

Microsoft Authenticator 上的自动填充已于 2025 年 8 月中旬停止，这是Microsoft简化自动填充工作的一部分。

尽管已保存的密码和地址在 Authenticator 中不再可访问，但你仍然可以在 Microsoft Edge 中跨设备轻松使用 、查看和管理保存的密码。

## Authenticator 自动填充更改是何时发生的？

- 2025 年 5 月，会显示应用通知，通知用户更改。
- 2025 年 6 月，在 Authenticator 应用中 添加 或 导入 新密码的功能已停止。
- 2025 年 7 月，使用 Authenticator 自动填充的功能已停止。
- 2025 年 8 月中旬，已保存的用户个人信息在 Authenticator 中不再可访问。

## 在 Authenticator 中保存的数据发生了什么情况？

- 密码和地址 ：这些密码和地址已安全同步到 Microsoft 帐户，并且仍可通过 Microsoft Edge 访问。 未保留生成的密码历史记录。
- 付款信息 ：出于安全原因，验证器中存储的付款信息已被删除，不再可访问。

## 保存的密钥是否仍在验证器Microsoft？

是。 Microsoft Authenticator 继续支持Entra密钥。

重要

如果已为工作或学校帐户设置了密钥，请确保 Authenticator 在 iOS/Android 设置中仍作为密钥提供程序启用。 禁用 Authenticator 作为密钥提供程序也会禁用密钥。

## 如何使用 Microsoft Edge 自动填充？

若要将自动填充与 Microsoft Edge 配合使用，需要按照以下步骤启用 Edge 作为自动填充提供程序。

- iOS
- Android
- Windows
- Mac

- 打开 Edge 并使用Microsoft帐户登录。
- 转到“手机 设置” ，然后选择“ 常规 ”。
- 选择“ 自动填充 & 密码 ”。
- 在“自动填充自”部分下，选择“Edge”作为密码管理器。

- 选择 “更改 ”，然后选择“ Edge ”。 注意 如果在 Authenticator 中为工作或学校帐户设置了“密钥”，请确保启用 “设备设置 ”“自动填充 > 其他服务 ”>下的“验证器”开关，以继续使用密钥。 禁用 Authenticator 将禁用密钥。 出于安全原因，付款信息仅保存在创建它的设备上，不会同步到 Edge 或任何其他应用。 2025 年 7 月之后，验证器中存储的任何付款信息将从你的设备中删除。 需要手动重新创建存储在 Authenticator 中的任何付款信息。
